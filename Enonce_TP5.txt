# Gestion d'une flotte d'ordinateurs

L'atelier de réparation et de vente d'ordinateurs a grandi.
Le prix de base des ordinateurs en vente en base c'est l'euros.
L'application de gestion de l'atelier informatique est maintenant utilisée par plusieurs profils : [Gestionnaire] ET [Administrateur];

L'entreprise souhaite :
- centraliser les appels API via une Gateway
- sécuriser les API avec JWT
- gérer les rôles et les droits
- mémoriser l'utilisateur connecté
- tracer les opérations effectuées
- consommer une API publique externe

# Objectifs pédagogiques

À la fin de ce TP, vous serez capable de mettre en pratique :

- Middleware
- JWT, Authentification, Autorisation, Roles et Claims
- HttpClientFactory
- API Gateway (YARP)
- Blazor
- Session utilisateur
- API distante

Architecture finale des appels de flux attendue : 

GestionOrdinateurs.Client (projet blazorapp)
   |
   v
Gateway (YARP)
   |
   +------ AuthentificationApi
   |
   +------ GestionOrdinateursApi
   |
   +------ ...

## Partie 3 - Sécurisation des APIs existantes (3 pts)

9. Configurer l'authentification swagger sur le projet  GestionOrdinateurs.API
`

Installer ces packages.....
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
dotnet add package Microsoft.AspNetCore.Identity.EntityFrameworkCore
dotnet add package Microsoft.AspNetCore.OpenApi
dotnet add package Swashbuckle.AspNetCore

Dans program.cs 

// ajouter swagger JWT
builder.Services.AddSwaggerGen(c =>
{
    c.SwaggerDoc("v1", new OpenApiInfo
    {
        Title = "GestionOrdinateurs",
        Version = "v1"
    });

    c.AddSecurityDefinition("Bearer", new OpenApiSecurityScheme
    {
        Name = "Authorization",
        Type = SecuritySchemeType.Http,
        Scheme = "Bearer",
        BearerFormat = "JWT",
        In = ParameterLocation.Header,
        Description = "Entrez : Bearer {token}"
    });
});

// Configuration JWT
var jwtKey = builder.Configuration["Jwt:Key"] ?? "";
var key = Encoding.ASCII.GetBytes(jwtKey);

builder.Services.AddAuthentication(options =>
{
    options.DefaultAuthenticateScheme = JwtBearerDefaults.AuthenticationScheme;
    options.DefaultChallengeScheme = JwtBearerDefaults.AuthenticationScheme;
}).AddJwtBearer(options =>
{
    options.RequireHttpsMetadata = false;
    options.SaveToken = true;
    options.TokenValidationParameters = new TokenValidationParameters
    {
        ValidateIssuerSigningKey = true,
        IssuerSigningKey = new SymmetricSecurityKey(key),
        ValidateIssuer = false,
        ValidateAudience = false
    };
    options.Events = new JwtBearerEvents
        {
            OnTokenValidated = context =>
            {
                Console.WriteLine($"Utilisateur utilisant un Token Valide --- {context.Principal?.Identity?.Name ?? "Anonymous"}");
                return Task.CompletedTask;
            },
            OnAuthenticationFailed = context =>
            {
                Console.WriteLine("Token Invalide");
                return Task.CompletedTask;
            }
        };
});

Dans appsettings.json
"Jwt": {
    "Key": "ma_longue_cle_de_test..................."
  }
`
